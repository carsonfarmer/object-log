# Git graph Task 4

Date: 2026-09-04

Code: `9ffcc00`, `83b84c9`, and native recovery follow-up `a4228b6`.

Repository open now loads refs and authenticated root references without pack
index GETs. Native recovery owns one lexical catalog under the same view and
operation. The private graph uses a deduplicated iterative work queue and
bounded nodes/edges; it stores metadata rather than blob contents. Commits
include every parent and tree; trees skip gitlinks; annotated tags retain the
full target chain. Known blob leaves require catalog membership but defer
content verification to selection/receive. Strict tree modes, filenames,
ordering, and nonadjacent duplicates are checked.

Seven focused graph tests cover both hashes, deep history, shared metadata,
invalid/missing objects, tags, unrelated blob reads, wide trees, and object/work
limits. Independent correctness and simplification review found two issues:
annotated tags forced unrelated blob reads, and Git ordering allowed two equal
filenames separated by another entry. Both were fixed and regression-tested.
Graph product code is 248 raw lines before its test module.
