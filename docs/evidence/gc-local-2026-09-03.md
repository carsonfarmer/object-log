## Criterion results

Each value is Criterion's 95% confidence interval.

| Workload | Time |
|---|---:|
| Start, 1,000 flat live objects | 1.883–1.907 ms |
| Start, 1,000 deep live objects | 2.956–2.990 ms |
| Start, 10,000 objects, half live, wide graph | 13.777–14.023 ms |
| Start, 100,000 unreachable objects | 79.513–80.497 ms |
| Fence lookup, planned reference among 100,000 candidates | 27.531–27.910 ms |
| Resume, 1,000 clean candidates | 0.901–0.911 ms |
| Resume, 1,001 candidates after a partial attempt | 0.840–0.848 ms |

The machine-readable intervals are in
[`gc-criterion-2026-09-03.tsv`](gc-criterion-2026-09-03.tsv). Criterion
extended the large cases until it retained 10 samples.

The start cases include bounded live-graph validation and scoped listing. The
fence case includes loading the durable plan, full graph validation, and
planned-key lookup. Resume repeats the complete positive set. The partial case
therefore submits 1,001 keys again, including keys already absent after the
first attempt.

`delete_attempts` counts candidate keys submitted for deletion. It is not an
HTTP request count.
